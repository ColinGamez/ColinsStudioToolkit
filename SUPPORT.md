# Support

For installation problems, feature requests, or unexpected behavior, [open a GitHub issue](https://github.com/ColinGamez/ColinsStudioToolkit/issues).

Include the extension version, VS Code version, operating system, steps to reproduce, and exact error message. Review screenshots and code examples before posting.

For activation issues, run **Lifetime License Status**, check your internet connection, and confirm you are using the purchase key from the live checkout. Keep the key private; never post it or payment details in an issue.

The [complete lifetime bundle](https://colins-marketplace-billing.vercel.app) costs CAD $14.99 once for the complete all-in-one toolkit. There is no subscription. Removing the saved key does not cancel or refund a purchase.
