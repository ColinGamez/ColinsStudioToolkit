# Colin's Developer Toolkit

One self-contained extension with developer tools, 32 color themes, and matching file icons. No standalone extensions are required.

> **Purchase required:** [CAD $14.99 once for lifetime access to the complete bundle](https://colins-marketplace-billing.vercel.app). No subscription. One purchase unlocks every built-in tool and theme.

## Get started

1. Install **Colin's Developer Toolkit**. All developer tools are built in.
2. [Buy the lifetime bundle](https://colins-marketplace-billing.vercel.app) and save your purchase key privately.
3. Run **Activate Lifetime Bundle** from the Command Palette and paste your key.
4. Run **Install Licensed Themes**, then press **Ctrl+K, Ctrl+T** to select a color theme. Use **Preferences: File Icon Theme** for matching icons.
5. Run **Quick Actions** from the Command Palette to find the built-in tools, or open **Command Center** in the activity bar.

Already own the bundle? Use your existing live purchase key; you do not need to buy again. If you previously installed standalone ColinGamez tools, you can disable or uninstall them after updating to avoid duplicate commands and views.

## Lifetime access and recovery

One CAD $14.99 payment covers every built-in toolkit feature. Signed activation refreshes after a day of online use and supports up to **30 days offline**. Initial activation, renewal, and theme downloads require internet access. Refunded or disputed purchases lose access at the next online check.

Keep your purchase key private to restore access after reinstalling. Use **Lifetime License Status** to check activation or **Remove Saved Purchase Key** to remove it locally; removal does not refund a purchase.

## Privacy and support

Payments use Stripe-hosted checkout. Extensions contact the billing service to verify purchases and deliver themes. Purchase keys are stored in VS Code SecretStorage. Never post keys or payment details in a public issue.

[Report a problem or request a feature](https://github.com/ColinGamez/ColinsStudioToolkit/issues). Include the extension and VS Code versions, steps to reproduce, and exact error. Review code or screenshots before sharing.

Previously released MIT versions retain their original rights. Original MIT notices are preserved.

## Source and development

This repository contains the all-in-one toolkit source. Existing command and configuration IDs beginning with `my-vsc-themes` are retained for compatibility; the current Marketplace ID is `ColinGamez.colins-developer-toolkit`.

Requires Node.js 24:

```sh
npm ci
npm run check
npm run check:themes
npm run package
```

The installer is written to `dist/colins-developer-toolkit-2.2.1.vsix` (using the version in package.json). The packaging script removes static theme contributions and theme assets from the public installer. Theme assets are delivered separately after purchase activation. Source assets and their original MIT notices remain in this repository.

`src/billing-config.json` contains only the live HTTPS billing origin and public verification key. It contains no payment credentials. Stripe and license-signing private keys belong only in the separate billing service and must never be committed here.

Theme-generation scripts remain available through `npm run build` for development. Changes to licensed theme assets require a coordinated billing-service theme-package release and checksum update before distribution.

GitHub Actions checks and packages pushes and pull requests. The manual Release workflow creates a GitHub release installer; it does not automatically publish to Marketplace. Upload the resulting VSIX using **Update** on the existing Developer Toolkit listing.
